# Material histórico

Esta carpeta conserva archivos que no intervienen en la ejecución, las pruebas ni
la entrega actual del prototipo. Se archivaron sin editar su contenido para evitar
confundirlos con los documentos activos, sin perder trazabilidad.

- `LEEME_PRIMERO_ORIGINAL.txt`: instrucciones del kit inicial. Su indicación de que
  `make verificar` falla con `TODO-1` describe el punto de partida, no el proyecto
  ya resuelto. Para la guía actual, volver a `../../README.md`.
- `ENTREGABLE_FINAL_GUIA_Y_RUBRICA_vista_previa.pdf`: vista previa conservada como
  documento auxiliar. El documento fuente y el PDF final permanecen en
  `data_benchmark_causal/causal_benchmark_synthetic/datasets/`.
- `distribucion_v1.0.0.sha256.txt`: hash SHA-256 del archivo de distribución
  `semana4-causal-v1.0.0.zip`. El ZIP no está en este árbol de trabajo; este texto
  sólo sirve para comprobar esa distribución externa, no para validar el proyecto.

Los resultados de ejecución y los hashes activos siguen en `artifacts/` y
`evidencia/`. Este archivo no sustituye `BASELINE.sha256`, que conserva la huella
del kit prístino.
